# Music

- `intro.m4a` - soundtrack of the intro (taken from the reference reel). It starts the moment the guest taps the book cover, and the intro pages are timed to it, so if you replace it keep the same 24-second structure.
- `main.mp3` - (add later) plays after the guest taps **YES** and the invitation opens, e.g. London Thumakda.

A music button in the bottom corner lets guests mute. If a file is missing, the page simply stays silent and the intro runs on its own timer.
